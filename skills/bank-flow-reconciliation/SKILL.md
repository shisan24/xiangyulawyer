# bank-flow-reconciliation

**适用场景**：查账/资金流向核对/流水凭证收据三方勾稽/给公安审计的资金说明材料。

## 工作流程（五步）
1. **制作核对表 Excel**：多 sheet 工作底稿，财务逐笔核对用。
2. **起草说明材料 DOCX**：按审计报告逻辑组织（资金性质结论→进卡明细→去向说明→结论→附件清单）。

## 核对表 Excel 设计（openpyxl）
- 颜色约定：黄=待核对、橙=待补充、绿=已核。表头蓝底白字。
- 数据来源列必须中性：写"银行流水"/"取现记录表"，不写 OCR/xls/img_xx。
- 修改后必须读回验证；注意表头起始行位置与列索引（曾出现列索引错位、金额写错列，改后须读回验证）。

## 关键陷阱：凭证号绝不从图片猜测对应
- **收款收据按联次判读盖章**：同一编号的多联单据，单位盖章通常只在付款人持有的那一联（收据联），公司留存的记账联常只有经手人签字、单位盖章栏空白。只看公司留存联会误判为"无单位盖章"，进而把出具主体搞错——核出具主体与印章必须找到付款人持有的联次，并逐联比对是否为同一编号、同一日期。

## 说明材料 DOCX 结构（审计报告逻辑）
一、说明事项 → 二、资金性质（进卡勾稽：流水↔凭证↔收据三方，结论"卡=公司资金通道"）→ 三、资金去向（按去向类型分列，亲属往来双向列示）→ 四、结论 → 附件清单。
- 亲属往来必须双向列示（只列转入会被"选择性呈现"质疑）；过渡资金做净沉淀配对；涉亲属受让的支出线主动写明资金性质与退还意愿，回避不如主动交代。
