# case-file-management

**适用场景**：案件文件标准化组织——目录/命名规范/客户地图/跨所归属重排。触发：整理案件材料、建目录、归档定位、跨所重排与归属纠错。

开始时按请求定位一个具体操作。先读下方章节索引，打开包含该操作的完整章节，再使用现有脚本、参考文件和资源；不能仅凭本短入口猜测参数或跳过原方法中的必要校验。

## 跨所／跨体系重排（归属判定与批量搬迁）
- **只移不删＋逐批台账**：每批生成 manifest（源、目标、件数、字节、移动后复核值、依据）与配套回退脚本，先干跑再执行；搬迁不得覆盖任何同名件。
- **删前先证明重复，“同名”不等于“同件”**：判重须去掉 `- 副本`／`(1)` 一类后缀再按字节（sha1）比对；同名而字节不同是版本差异，两份都留。**去后缀后全库找不到同件，说明该副本是本树唯一留存**，应整目录原样改挂到对应栏（保留内部结构与来源标记）并出台账，而不是删；目录名带“垃圾”“旧”“临时”的一律先抽样读正文，目录名不构成处置依据。
