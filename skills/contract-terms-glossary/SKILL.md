# contract-terms-glossary

**适用场景**：中国合同起草审查关键概念词典——跨书作者用法（三观四步法系列/常用合同卷/雷霆/三十讲等），供合同审查类技能引用。

# 合同起草审查关键概念词典
> 用途：保存"作者用某个词的方式和字典不一样"的关键概念（如三观四步法系列的"选择型关系""劳务雇佣"自设定义）。这类词若按字典义理解，下游合同审查技能会给出错误建议。

## When to Use
- 审查/起草合同时遇到需要"作者特殊用法"校准的术语（任意解除权、选择型关系、三包、劳务雇佣、行纪等）
- 查某术语是否有"与常识不同的关键区分"

## 提取工作流（供未来组复用）
1. 提取标准：作者反复使用（≥3次）/ 明确"所谓X是指…"定义 / 用法与常识不同 / 核心论点组成词。预期 5–20 条，宁多勿漏；>30 条说明收了普通词汇。
2. 去重/输出细节与全读变体边界见 `windowed-text-extraction` 技能（user-owned）。
