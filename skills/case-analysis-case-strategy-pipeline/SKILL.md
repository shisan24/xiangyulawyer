# case-analysis-case-strategy-pipeline

**适用场景**：复杂案件的事实要件、证据、类案研究与诉讼策略贯通流程；不用于简单条文定位。

## 风险敞口量化与既有成果复核（分析案件必做）
**按日违约金先算再排序。** 诉请出现「按合同暂定总价万分之五」「按日万分之五」「逾期每日」的，先算日额（合同价×0.0005）和起算日至当日的累计额，再与分项诉请比大小。建工案里退场移交这一项常超过全部实体诉请之和，不量化就会把最大敞口排在质量、工期之后。同时看诉请是否写明「每日」：只写「按万分之五标准」的，先主张计算方式不明确，再退到实体抗辩。
**诉请总额一律复算，不沿用旧文书。** 从起诉状或变更申请书的各分项相加复算总额；旧意见书写的总额与分项对不上时按错误处理，在交付中写明差多少、差在哪几项，不照抄。分项变更后其余项不变的，用变更后分项重算，不假设总额不变。

### 公司法速查（源：朱锦清《公司法学》第三版，节选 p77–450｜PDF 989 页）
248 条，五册。**教科书节选**：只取第四章至第十章中能用于中国实务的判断规则，公司证券／会计／上市公司／并购／控制权争夺未拆：
1. **刺穿面纱不要只说"人格混同"**：书里把它拆成三个必要条件＋一个案情标准（资本显著不足或主体混同），并区分合同案子（还须证明欺骗、隐瞒、误导致债权人不自愿）与侵权案子。
2. 隐名股东确权有两条路径（其他股东过半数同意 vs 实际出资＋参与经营），且代持不得对抗善意第三人。
3. 本书为学理与比较法研究（作者大量引美国判例），**引用前按现行《公司法》（2023 修订）核对条号**；标注"美国法（比较法参考）"的条目不得当作中国法适用。
