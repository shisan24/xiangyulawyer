# corporate-system-compliance-review

**适用场景**：企业制度/事权清单/采购办法合规审查——含国企三重一大/国资交易。触发：审制度、合规分析。

# 企业内部管理制度合规审查
审查国有/民营企业内部管理制度（管理制度、事权清单、采购办法、实施办法、实施细则等）的法律合规性。

## 与制度严格筛选及行政规范性文件审查的分工
- 行政规范性文件合法性审核、需要五类风险下限和逐条台账的任务，转入 `corporate-regulation-review`。
- 一般企业制度或事权清单需要先做严格筛选时，可先由 `corporate-regulation-review` 初筛，再由本技能按企业属性和制度范围深审。两套技能可以协同加载，不互相替代。

## 党委会议事规则（党内制度）的独立审查线
党委（党组）议事规则与经营类制度审法不同：重点不是交易条款，而是**事项范围、程序门槛与责任表述**。三条必做：
1. **“一定金额以上”必须落到附件清单**。议事范围用词模糊而事项清单未随文，决定与前置讨论的边界就不可执行；同时要求写明清单的制定与修订程序。
2. **议事门槛与责任用语回归党内法规**。“应到会委员人数”含义要写死，干部任免三分之二到会的特别规定要与开会门槛条款打通；责任条款用《中国共产党问责条例》的“第一责任人”“主要领导责任”与免责情形表述，不自制一套责任规则。

## 与合同审查的区别
| | 合同审查 | 制度审查 |
| 审查对象 | 双方/多方协议 | 单方内部规则 |
| 法律框架 | 民法典合同编为主 | 公司法+国资监管+行业法规 |
| 风险关注 | 权利义务不对等/违约救济 | 越权/程序瑕疵/上位法冲突 |
| 输出格式 | 法审意见单/修订稿 | 风险清单+修改建议（非修订稿） |
| 合同模板审查 | 审查单个合同 | 审查制度内嵌的合同范本——视为制度一部分 |
但方法论相通：宏观（能不能做）→ 中观（程序对不对）→ 微观（条款怎么写）。加载 `contract-review-methodology` 补充思维框架。

### 九大合规维度核查表
| 核查维度 | 制度审查中的落点 | 审查要点 |
| **招标采购合规** | 采购办法、招标管理办法 | 是否界定依法必须招标范围（16号令+843号文）？制度是否禁止"招大定小""明招暗定"、中标后另行签订背离性协议？实质性条款与招标文件一致性要求 |
| **三重一大决策** | 事权清单、决策权限表 | 金额/期限/担保门槛是否触发党委前置研究、董事会/总办会决策？决策文件（会议纪要、表决记录）与合同签署主体、金额、条款一致性要求 |
| **关联交易审查** | 关联交易管理制度 | 是否定义关联方范围（股东/实控人/董监高近亲属控制企业）？回避表决、独立董事意见、信息披露程序；定价公允性要求（避免利益输送） |
| **合规前置审查留痕** | 合规审查流程 | 重要合同签订前是否经合规管理牵头部门/法律顾问审查并留存意见？（《中央企业合规管理办法》要求） |
| **国有资产保值增值** | 定价/付款/担保条款审查 | 无偿让利、超常规账期、无对价担保等导致国有资产流失或不当风险敞口的情形 |

### 国企语境风险速查（优先核查信号）
| 风险信号 | 说明 |
| 强制招标项目未招标，或以"战略合作""框架协议"名义规避招标 | 违反《招标投标法》第49条，可处合同金额千分之五至千分之十罚款 |
| 金额/担保/期限接近或超过决策门槛但无决策文件 | 决策程序缺失，构成越权代理及内部问责风险 |
| 关联交易未履行回避表决及公允定价说明 | 损害国有资产的关联交易，构成违规经营投资追责情形 |
| 合同缺少审计/监督配合条款 | 国企对外合同一般应保留审计署、国资委、纪检监察机关检查权 |

### 市场/行业惯例基准（国企语境，数字可核查）
| 工程款支付周期 | 符合《保障中小企业款项支付条例》，一般不超过验收合格后60日 | 60-90日 | 90日以上或无明确约定 |

### 底线与免责事项
- **不替代内部合规审批**：审查为法律及合规风险识别参考，不替代合规管理牵头部门、总法律顾问及上级国资监管机构的正式审查、核准或备案
- **禁止杜撰**：不得编造决策文件、招标文件等不存在的材料内容
- **兼顾正面评价**：报告应包含"已审查、可接受"及合规维度中"符合"的条目，避免只列风险不列结论

## 审查流程
1. **自审撤回** — 第一遍完成后逐条反检，撤回不成立的意见（附撤回原因），降级高估的风险。标准：8-13条初筛→复核后撤回约半数→保留核心项。撤回信号清单：
   | 参考依据含合同（"根据《XX合同》"） | 措辞问题≠法律风险，降🟢建议 |
   | "适时启动法律程序" | 国企制度标准表述 |
2. **AI 交叉复核** — 用 Qwen 3.7-max（DASHSCOPE_API_KEY，temperature=0）对审查意见做二次审查。**必须附完整源文件原文**（简化摘要会导致 Qwen 误判引用事实为编造）。五个复核维度：①数据准确性（条款编号/引用原文）②定性恰当性（风险等级）③关键遗漏 ④表述精确性（过度推断/无力措辞）⑤撤回合理性。Qwen 发现须逐条对照原文核验后再定（确认采纳/部分接受/不采纳附理由），不盲从。
3. **风险定级** — 🔴高风险（法律效力风险/重大利益损害）/ 🟡中风险（合规瑕疵/可完善）/ 🟢无问题
4. **汇报** — 按文件逐一列出发现，每项标注风险等级+修改建议

## 合同模板审查的甲方立场模式
过滤基于公平原则或法院调整顾虑的建议（如违约金过高可能被调减→但这是保护甲方的条款，不删）。

## Pitfalls
- 不要用"法审意见单"格式——制度审查不是合同审查，格式不同
- 制度审查的"合同模板"部分审查深度=正式合同审查，不能因为"只是附件"就跳过
- 国企制度必查：三重一大程序、党委会前置、集团审批层级——这是刚性合规项
- 引用上位制度时核实名称是否准确——事权清单常引用《XX管理办法》，需确认该办法是否已发布
