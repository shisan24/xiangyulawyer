# patent-term-extension

**适用场景**：药品专利期限补偿（PTE）业务，含上市许可日认定、证书更正件、药监局取证。触发：专利期限补偿、PTE请求、药品专利补偿。

## 触发条件
- 药品专利期限补偿请求、审查意见答复、审批决定争议

## 法条框架（2026-08 核实）
| 《药品注册管理办法》第39条 | 生产工艺、质量标准、说明书、标签作为证书附件，共同构成注册批准文件体系（元典核实为39条，非40条） |
| 《专利审查指南》第五部分第九章3.1-3.8 | 补偿条件（授权公告日早于上市许可批准日/专利有效/未获过补偿/权利要求覆盖新药等）、请求提出、证明材料、适用范围（创新药+限定改良型新药2.1/2.4类等）、补偿期限、审批 |
| 《专利审查指南》第四部分第一章7.3节 | 审查决定的更正限于"明显文字错误"——反驳以《修改更正通知书》撤销实体审批决定 |

## 上市许可日认定：更正件 vs 原批准日期
1. 原证书已明确废止，非现行有效注册文件，不得作为行政审查依据
2. 批准附件是许可内容组成部分；参数错误致检验方法不可实施=许可内容不可执行，企业无法合法生产上市
**反面风险：** 行政许可更正通常具有溯及力（批准日期不变论）；"废止"对象是证书载体而非批准行为本身。

## 药品注册证书关键字段核验
- 更正件备注标准格式："此件为更正件，更正日期为X。原批准日期为Y，原证书、附件废止。"

## 国知局审查流程与文书链
请求（上市许可批准之日起3个月内提出）→ 审批决定（补偿天数、原/新期满日、补偿期年费）→ 《修改更正通知书》（可撤销已生效决定）→ 审查意见通知书（限1个月陈述补正）→ 不予补偿决定 → 行政复议（60日）/行政诉讼
- 已生效具体行政行为具有公定力、确定力，非经法定程序不得撤销
- 更正程序不能替代撤销程序（审查指南7.3节仅限明显文字错误）

## 药监局书面意见获取策略
- **职权边界**：注册证书由国家药监局核发；省局仅属地监管（证书抄送持有人所在地省局，非发证机关无认定权）

## Pitfalls（实战教训）
- **模型声称"某规范明文规定X"必须回一手文件核实**——复核中 Qwen 两次声称指南规定"上市许可之日=批准日期"（幻觉）；Kimi 声称《药品注册管理办法》39条是40条——元典核实39条正确。涉及法条/指南内容声称，用元典 ft_search 或 PDF 全文搜索验证
