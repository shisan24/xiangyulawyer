# media-reputation-infringement-response

**适用场景**：报道或平台内容侵权，客户要删文、更正、投诉举报。媒体失实报道与网络名誉权、商誉侵权的分层处置流程。

## 开工
先读原文再判断，不以搜索结果摘要、标题或他人转述代替原文。读法是打开原页面取正文：`browser_exec` 用 `new_tab` + `wait_for_load`，再以 `js('document.title')` 和 `js('(() => document.body.innerText.slice(金额00))()')` 取文字；取正文时按标题与署名区间截取，页面文字里混有推荐流和热榜内容，不能当成报道内容。直接抓取接口依赖后端配置，报错或返回空时改走浏览器，不因工具状况降低核查标准。

## 分层处置顺序
   - 平台视频页在未登录状态下不加载视频本体，页面只给出平台自动生成的章节摘要。摘要不是视频口播或画面的证据，不得当作原话写进函件；画面与口播须自己播看并录屏后再据以主张，未核验的表述一句不写。
平台通知不实可能承担错误通知责任（民法典第一千一百九十五条第三款），陈述与附件必须自洽；不确定的事实不写成确定判断。

## 支撑文书与生效裁判的提交策略
- 任何对外陈述（「已固定证据」「已向发布者发出通知」）必须与实际已完成的动作一致，动作先做完再写进函件。

## 关键风险
- 权利主体必须与报道所指对象和工商登记一致。报道对「商场」「登记主体」的表述本身可能有误，先核清主体再落款，避免以错误主体投诉被驳回。
