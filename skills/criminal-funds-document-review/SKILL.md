# criminal-funds-document-review

**适用场景**：Use for criminal funds docs and linked civil-case review.

## 适用场景
- 录音要求、财务口径、银行流水和司法会计鉴定请求同时存在的材料包。
本技能处理的是事实、来源、证据层级和交付一致性，不替办案机关作犯罪认定。

## 核心原则
1. **两份成果同步**：情况说明与资金流向图解是并列文件，不互相嵌套。正文新增一组资金线索，图解必须同步增加对应图、表或说明框，案号、金额、日期、主体、不确定性和证据限制保持一致。

### 一、建立材料边界和来源矩阵
法律分析意见和模型复核报告只作索引。关键金额、日期、主体和方向必须回溯一手材料。

#### 2. 公司账务层
账簿、记账凭证、收款收据可证明公司如何记账、如何出具凭证和公司掌握的财务口径。账面记载不等于资金实际去向，须与银行流水逐笔对应。

#### 3. 民事材料层
- “不对民事案件实体责任或刑事性质作出判断”。

### 三、关联民事案件的组装方法
1. 对多案合计保留原材料的不同口径。若“12案合计”和“14案合计”加总后不一致，写“合计存在口径差异，以原始诉讼材料和完整账目核对为准”，不要自行算出第三个总额。
2. 对民事材料与银行表的人名、日期不一致，直接列出差异，并把核对动作指向原始流水。

### 五、DOCX与图解增量修改
- 写入后读回全文，检查标题顺序、编号、空段、旧标题、旧金额、旧人名和附件残留；
- HTML新增图页时同步检查 `<div>`、`</div>`、`<table>`、`</table>` 数量，页数、图号和收尾标签；

### 五-A、主文精简与资金流向图解减负
1. **删重复，不删核心证据**：完整重复的实例表、重复结论段和纯重复图页可以删除；账面与流水的核心明细、金额合计、账户方向、关键资金链、证据限制和鉴定请求不得因“精简”被一并删掉。
2. **保留可核验口径**：精简只改变呈现范围，不改变原始事实。保留“材料记载”“部分”“不代表全部规模”“需完整流水核验”等限定语，不把民事诉讼主张升级为刑事事实。
3. **双层验收**：DOCX用Word/WPS实际渲染，HTML用DOM检查页面尺寸和越界；浏览器当前视口截图未显示页面底部，不等于HTML被裁切，必须以DOM几何或完整打印结果判断。

### 六、对抗复核和迭代收敛
大幅新增关联民事材料后，不能沿用新增前的复核结果。每轮复核携带上一轮问题清单，逐条标记：
复核报告不是事实来源。完整模型任务无回执时不得报“通过”。可以将复核范围收窄为“新增段落＋对应源材料”的定向复核，但必须在记录中写清复核范围和未覆盖部分。修复后必须重新读回DOCX、重新扫描HTML并重新校验双文件一致性。

## 交付前清单
- [ ] 当前送审文件边界已列明，旧稿未混入结论。
- [ ] 原始银行表已逐行核对关键账户方向。
- [ ] 账户尾号相近但方向不同的记录已区分。
- [ ] 合计口径冲突已披露，未自行相加。
- [ ] DOCX段落顺序、编号、空段和旧残留通过读回检查。
- [ ] HTML页数、图号、闭合标签、图注和来源限制通过结构检查。
- [ ] dsh/模型复核只作为对抗检查，最终事实回到原始材料。
