# construction-contract-review

**适用场景**：建设工程合同审查——资质定性优先、无效风险双向分析。触发：审施工/装修合同。

# 建设工程合同审查（资质风险专项）
> 配合 `contract-review-methodology`（通用三观四步法）使用：方法论负责审查思维框架，本技能负责建设工程类合同特有的资质定性问题、无效风险处理和乙方立场交付纪律。

## When to Use
- 审查装修、施工、分包、EPC、"服务委托"名义的工程类合同
- 需要判断合同名称与实质定性、无效风险及后果

### 第一步：资质与定性（最高优先级，先于一切条款审查）
1. **确认签约方资质**：建筑装修装饰工程专业承包资质（专业承包序列，《建筑业企业资质管理规定》第5条）。无资质是既成事实时，不要停留在"提示风险"，直接进入无效后果分析。
2. **豁免边界**：住宅室内装修可由业主自行装修、不强制资质；公建（物业用房、商铺、办公）装修+水电改造在资质范围内，无豁免。

### 第三步：交叉引用冲突检查（逐条深度审查必做）
- 同事项两处口径相反（如增项付款时点）
- 假设性条款无清单支撑：顺延情形假设甲方供材但无供材范围清单
- 法定义务错位：验收备案（建设单位义务）写进承包方节点
- 术语漂移：同一概念两套口径（"封样"、"合同总价/暂定总价"）、旧版残留引用（"监理"）

## 核实纪律（被要求"逐条验证"后沉淀）
- 法条引用必须核实原文再写进批注：用所属法规库逐条核对原文（元典 MCP `rh_ft_detail`，fgmc 支持简称模糊匹配，如"建设工程质量保证金管理办法"；`rh_ft_search` 作备选）
- GB工程建设标准名称：市监总局标准公开系统（openstd.samr.gov.cn）不收录工程建设标准；改用元典搜住建部发布公告确认标准全称（如"住房和城乡建设部关于发布国家标准……的公告"）
- 措辞精确：条例第60条无资质情形是"予以取缔"，"责令停止违法行为"是超越资质情形的用语，别混

### 招投标与合同效力
- **无效情形清单**（8类）：无资质/应招未招/中标无效/转包/违法分包/支解发包/未取得规划许可等；**转包无效不当然导致总包合同无效**
- **无效后果双轨**：外部后果（行政处罚/刑事）+内部后果（验收合格→折价补偿参照约定，无违约金/利息/默示条款）

### 结算与优先受偿权
- **优先受偿权**：主体（承包人；实际施工人仅在发包人欠付范围内）、放弃"原则有效例外无效"（损害建筑工人利益无效）、行使期限（18个月，2021解释）、以房抵债须在期限内+四风险、债权转让后仍以转让人名义索赔

### 条款设计
- **单价vs总价**：总价合同≠一口价（清单总价模型名为总价实为单价）；价格调整机制=风险承担机制，"无限风险"条款边界；暂列金额≠暂估价
- **垫资**：政府投资项目不得垫资建设；约定利息支持，无约定不支持；借款形式仍可认定垫资
- **背靠背条款**：效力边界（总包付款条件与发包人付款挂钩，不能对抗实际施工人/转包无效情形）；分包合同传导条款设计

### 特殊主体与模式
- **非工程所有人发包**：不影响合同效力，但优先受偿权存疑+支付风险
- **工程总承包**：适用施工合同规则；《发包人要求》核心地位；与买卖/承揽定性界限（EPC当买卖无效）

### 通用条款必须抽查，不能当标准文本跳过
逐条 grep 通用条款"视为认可/视为同意"，判断方向：对发包人不利的改为"逾期视为不同意，按争议解决约定处理"（19.4(2) 承包人不答复视为认可发包人索赔的保留）。

### 专用条款专项点（发包人立场）
- **发包人逾期付款责任空白＝日万分之五**（年化约18%）：《保障中小企业款项支付条例（2025修订）》（国务院令第802号）第17条——未约定利率按每日万分之五。16.1.2(2) 空白必须填"按应付未付金额以合同订立时1年期LPR计息"（条例要求约定不低于LPR，写LPR合规且成本最低）
- **商票强制接受**："承包人均应予以接受"违反条例第11条（不得强制中小企业接受商业汇票、不得变相延长付款期限）——改"具体支付方式及期限以双方书面确认为准；票据期限不超过对应付款节点的约定付款期限"
- **异常恶劣气候认定标准过宽**：如"日降雨>50mm的雨日超过1天、38℃高温>3天"在当地夏季常见，顺延事由被放大——按工程所在地气候收紧并保留24小时书面通知+气象证明+照片程序门槛
- **分包范围"/"与分包备案程序并存＝自相矛盾**：市政道路含照明/绿化/交安等专业工程必然分包，全禁逼承包人隐蔽违法分包（分包合同无效+实际施工人可依解释一第43条直接起诉发包人在欠付范围内担责）——列明允许分包的专业工程+保留备案/资质审查/更换权
