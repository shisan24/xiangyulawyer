# ipo-securities-counsel

**适用场景**：IPO／北交所上市律师业务：条件、工作清单、风险与收费。触发：IPO、新三板、上市辅导。

## When to Use
工作规则入口先加载 lawyer-workbench。文书起草排版走 legal-document-workflow，格式闸门走 de-ai-format-gate，法规检索走 legal-retrieval。

## 一、先定路径，再谈条件
1. **板块决定条件和时序**。沪深北交所与港股的发行条件、审核程序、披露准则完全不同，规则清单按目标板块现行文本取，不混用、不互套。
2. **条件核对必须落到数据**。市值与财务指标标准须以发行人经审计的最近两个会计年度数据测算。未取得审计数据前，只列标准并写明「尚不能判断」，不推定是否符合。

## 三、交付形态（这类项目的成果形状）
三份都要「具体详细」：每一行落到条款号、查验对象、取得方式与成果文件，不写空泛口号。这份组合同时是报价支撑——服务成果清单承载「工作量」，风险清单承载「责任对价」，收费合规专章承载「合规边界」。

### 清单类成果的两态（尽调清单尤其）
尽调清单按用途分两态，交付前先确认要哪一种，不默认全给：
- **内部工作版**：在对外版基础上加「核查方法与关注要点」列，写「怎么查」而非「查什么」（如股份代持：不得仅以股东承诺认定不存在代持，须以协议、对价、资金来源、支付方式、经营决策参与情况等客观证据相互印证；银行函证：不得由发行人代为转交或传递）。用于核查台账与底稿索引。
两态同源：一份结构化数据（专题 → 事项 → 资料 → 核查方法）生成两版，不维护两套文本、不手工两处改。

## 五、常设规则
1. **不承诺时间**。审核与注册时限不含补充或修改申请文件、现场检查、现场督导与专项核查的时间，项目周期由整改进度与问询轮次决定，谈判与报价时不对完成时间作保证性承诺。
2. **独立性**。同一律所不得同时为同一次发行的发行人和保荐人（承销商）出具法律意见。承接前完成全所利益冲突检索，范围含控股股东、实际控制人、董监高、重要子公司。
3. **事实边界**。未取得发行人内部资料时，清单中的公司信息全部标注「来自公开渠道检索，未经发行人确认」，并声明不构成对具体事项的法律意见、不构成对发行上市结果的意见或承诺。
4. **规则核验**。条款号来自专业法规数据库检索时，标注核验日期与「正式引用前按官方发布文本复核版本与时效」。数据库元数据异常（发布机关或发布日期与正文矛盾）如实披露，不静默使用。

## 六、挂牌与上市：工作量与报价分段
| 门槛 | 股本总额不低于 500 万元；持续经营不少于两个完整会计年度；股权明晰、治理健全、业务明确具有持续经营能力、主办券商推荐并持续督导。**无净利润等财务硬门槛** | 四套上市标准择一，另有净资产、发行后股本、股东人数、公众持股比例等要求 |
| 审核 | 全国股转公司审核 | 北交所审核（通常两到四轮问询）加证监会注册，可能现场检查或督导 |
| 周期 | 最快四到六个月走完全程 | 前置挂牌满十二个月，申报到上市通常一到两年 |
「已挂牌满十二个月」的计算标准已由 2023 年 9 月证监会关于高质量建设北京证券交易所的意见之后的改革举措优化为**以交易所上市委审议时为节点**，自进入创新层之日起即可提交申报文件，不必等到满十二个月才动手。适用时以现行规则与交易所规定为准。

## Pitfalls
- **挂牌多年的企业要单做「披露衔接」专项**：检索挂牌以来全部定期报告、临时公告、定向发行、股份交易与自律监管措施，形成披露沿革清单，再逐项比对本次申报文件。别等问询函来提。
- **创新层资格是持续条件**：分层管理办法有修订，按现行进入与维持条件逐项核对，一旦不再符合创新层条件直接影响发行条件。
- 两份 DOCX 交付前跑 de-ai-format-gate 闸门；生成侧把引号归一放在唯一的文本插入入口，长文档用数据驱动脚本一次重建，不逐段手工拼。
