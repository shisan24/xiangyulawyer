# execution-guarantee-agreement

**适用场景**：执行担保/以物抵债三方协议起草。触发：执行担保协议、三方执行担保、恢复执行+担保、终本化债。

# 执行担保协议起草（终本恢复执行 + 以物抵债）
执行担保协议 = 三方（申请执行人/被执行人/案外担保人）约定以担保财产清偿执行债务的协议，配套恢复执行→查封担保财产→评估拍卖→以物抵债流程。

## 法律框架速查（条文已核验，2026-08）
| 第12-13条 | **担保期间未记载默认为一年**——协议必须写明至债务清偿完毕 |
| 拍卖变卖规定（2020修正）第16条 | 流拍后申请执行人申请/同意以**保留价**接受→法院应交付抵债（合法的"流拍后以物抵债"依据） |

## 协议结构（七条模板）
1. 鉴于/背景：调解书→执行案号→债务金额→**终本事实+乙方多案被执行**（"为什么同意抵债"必须拉齐，甲方国资决策依据）
2. 担保范围与专属性：仅担保房产为限；丙方承诺不设新权利负担/不用于其他债务担保；清偿顺序（本金→利息，可约定）；**差额向乙方追偿保留**；剩余价款返还丙方
3. 附则：份数、附件清单、生效条款

## 设计要点与陷阱
- **担保期间默认为1年**（执行担保规定12条），必须写明至清偿完毕
- 解除权与担保书兼容：**担保书无条件承诺 + 协议附解除条件**可以并存——解除权行使后丙方向法院撤回担保书+甲方申请解封，法院层面无瑕疵
- "排除参与分配"只能写成**丙方承诺义务**（不为其他债务担保等），不能写成对抗第三人的绝对化表述；注意506条第2款：对查封财产有优先权/担保物权者仍可直接主张
- 权利瑕疵保证：丙方陈述保证"不存在"优先权负担，违反则赔偿——不是"放弃权利"（第三人的权利无法放弃），审查时注意此区别

## 流程
1. **通读全料**：协议+全部附件+旧版协议+审查意见书+执行概况+语音记录（如存在）——旧版文件揭示谈判历史和方案演变（如债务加入→执行担保）
2. 主体核实：元典企业信息核对三方名称/代码/法代/住所，查关联关系和涉诉（乙方多案被执行、丙方商品房纠纷=关键风险信号）
3. **Council 输出三阶过滤**：常识排除（删除解除权=商业前提不可行；"放弃优先权"=误读陈述保证；"法院必拒"=担保书无条件+合同解除权可并存）→ 采纳真实风险（承诺过强/空白机制/解除后自保路径）→ 修正
4. **页数控制**：Word COM 转 PDF（pywin32，Visible=False 不弹窗）+ fitz 数页验证；超页按"删冗余不动实质"顺序压——删空行段 → 合并重复条款（如差额处理与清偿顺序重复）→ 条款合并（1.1-1.3 合一、附件列表五行合一）→ 左右边距 3.17→2.5cm（合同标准）→ 文字压缩（重复指代合并）；签署页用 page_break_before 独立（"本页无正文"规范）
5. **表格附件必须用真 Word 表格**（Table Grid），禁止空格对齐伪表格——Word 渲染列不齐、折行错位（附件"乱"的根因）

## Pitfalls
- **DOCX 修改后全量读回验证结构元素**（标题/副标/签署页/案号），不能只验证改动段落——曾发生 run 级修改导致副标段+签署页案号意外消失，只验证关键词未发现，全量打印才暴露
